# Provenance

This repository was prepared from the final iteration of an Internet Application Development course project. It contains the completed frontend and backend source, a sanitized standalone database initialization script, demo data, and tests. The course assignment PDFs, starter handout directories, build artifacts, submission ZIP, and local database credentials were deliberately excluded. A hard-coded plaintext demo administrator account was also removed from the standalone SQL script.

Some starter code and assets may originate from the course handouts. This repository does not claim sole authorship of those materials or assign them a new license. The README describes the final system's implemented behavior and explicitly notes its demo-only security limitations.
